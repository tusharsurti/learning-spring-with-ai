# SOAP Test Automation with Robot Framework

This project contains automated tests for the Number Conversion SOAP web service.

## Prerequisites

* Python 3
* pip

## Setup

1. Clone the repository.
2. Navigate to the project directory.
3. Install the dependencies:
   ```
   pip install -r requirements.txt
   ```

## Running the tests

To run the tests, execute the following command from the project root:

```
robot -d results tests
```

The test results will be available in the `results` directory.
